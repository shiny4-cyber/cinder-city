An open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's bounty: a city you
cross on foot and by car, traffic and pedestrians, cars to steal, a wanted level and police that pursue,
missions with payouts, combat, and a HUD with a minimap. Static files, no build step, no network at run time.

Run it: `node serve.ts` then open http://localhost:8080. Hand it in: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
